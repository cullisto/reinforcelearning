# 2.4 逐次的な実装(Incremental Implementation)

> 原著: Richard S. Sutton, Andrew G. Barto, *Reinforcement Learning: An Introduction* (2nd ed., 2020)
> 対象箇所: Chapter 2, Section 2.4 Incremental Implementation(原著 pp.30–31)

これまでに論じてきた行動価値手法は、いずれも観測された報酬の標本平均として行動価値を推定するものだった。次に、こうした平均を計算量的に効率よく――特に、一定のメモリと、各タイムステップあたり一定の計算量で――計算する方法という問題に目を向けよう。

## 逐次的な更新式の導出

表記を単純にするため、ここでは単一の行動に注目する。$R_i$を、この行動が$i$番目に選ばれた後に受け取った報酬とし、$Q_n$を、その行動が$n-1$回選ばれた後の行動価値の推定値とすると、これは単純に次のように書ける。

$$Q_n \doteq \frac{R_1 + R_2 + \cdots + R_{n-1}}{n-1}$$

素朴な実装は、すべての報酬の記録を保持しておき、推定値が必要になるたびにこの計算を行う、というものだろう。しかしこれでは、より多くの報酬を目にするにつれて、メモリと計算量の要件が時間とともに増大していってしまう。報酬が1つ増えるごとに、それを保存するための追加のメモリと、分子の和を計算するための追加の計算が必要になる。

お察しの通り、これは本当は必要ない。各新しい報酬を処理するのに必要な計算量を小さく一定に保ちながら、平均を更新するための逐次的な式を考案するのは容易である。$Q_n$ と $n$番目の報酬 $R_n$ が与えられたとき、$n$個すべての報酬の新しい平均は、次のように計算できる。

$$
\begin{aligned}
Q_{n+1} &= \frac{1}{n}\sum_{i=1}^{n} R_i \\
&= \frac{1}{n}\left(R_n + \sum_{i=1}^{n-1} R_i\right) \\
&= \frac{1}{n}\left(R_n + (n-1)\frac{1}{n-1}\sum_{i=1}^{n-1} R_i\right) \\
&= \frac{1}{n}\Big(R_n + (n-1)Q_n\Big) \\
&= \frac{1}{n}\Big(R_n + nQ_n - Q_n\Big) \\
&= Q_n + \frac{1}{n}\Big[R_n - Q_n\Big]
\end{aligned} \tag{2.3}
$$

これは $n=1$ の場合にも成り立ち、任意の $Q_1$ に対して $Q_2 = R_1$ が得られる。この実装は、$Q_n$と$n$のためのメモリしか必要とせず、各新しい報酬に対して必要な計算も式(2.3)の小さなものだけである。

## 更新則の一般形

この更新則(2.3)は、本書全体を通じて頻繁に登場する形をしている。その一般形は、次の通りである。

$$\text{新しい推定値} \leftarrow \text{古い推定値} + \text{ステップサイズ} \Big[\text{ターゲット} - \text{古い推定値}\Big] \tag{2.4}$$

式 $[\text{ターゲット} - \text{古い推定値}]$ は、推定値における**誤差(error)**である。この誤差は、「ターゲット」に向かって一歩進むことによって縮小される。ターゲットは、ノイズを含んでいるかもしれないが、進むべき望ましい方向を示していると想定される。例えば上の場合では、ターゲットは$n$番目の報酬である。

逐次的な手法(2.3)で用いられているステップサイズ・パラメータ(StepSize)は、タイムステップごとに変化することに注意されたい。行動$a$についての$n$番目の報酬を処理する際、この手法はステップサイズ・パラメータ $\frac{1}{n}$ を用いる。本書では、ステップサイズ・パラメータを $\alpha$、あるいはより一般的には $\alpha_t(a)$ と表記する。

## 完全なバンディット・アルゴリズムの疑似コード

逐次的に計算される標本平均と$\varepsilon$-貪欲な行動選択を用いた、完全なバンディット・アルゴリズムの疑似コードは、以下の通りである。関数`bandit(a)`は、行動を受け取り、対応する報酬を返すものとする。

```
単純なバンディット・アルゴリズム

初期化, a = 1 から k まで:
    Q(a) ← 0
    N(a) ← 0

無限に繰り返す:
    A ←  argmax_a Q(a)      確率 1-ε で(同点は無作為に解消)
         無作為な行動        確率 ε で
    R ← bandit(A)
    N(A) ← N(A) + 1
    Q(A) ← Q(A) + (1 / N(A)) [R - Q(A)]
```

---

## この節のポイント(要約)

- 標本平均による行動価値の推定は、過去のすべての報酬を保存し都度計算し直す必要はなく、**逐次的(incremental)**に更新できる: $Q_{n+1} = Q_n + \frac{1}{n}[R_n - Q_n]$(式2.3)。必要なメモリは $Q_n$ と $n$ のみ、計算量も定数。
- この更新式は、本書全体で繰り返し現れる一般形に従う: **新推定値 ← 旧推定値 + ステップサイズ × [ターゲット − 旧推定値]**(式2.4)。「ターゲット − 旧推定値」は推定誤差であり、これを縮める方向に一歩進む、という発想。
- 式(2.3)で使うステップサイズは $\alpha = \frac{1}{n}$ であり、行動が選ばれるたびに変化する(のちの章では一般に $\alpha$ や $\alpha_t(a)$ と表記)。
- この考え方に基づく、$\varepsilon$-貪欲な行動選択を用いた完全なバンディット・アルゴリズムの疑似コードが示されている。
